LIBRARY / 02

The essentials, covered.

Encoding, decoding and rendering, with a small public interface and explicit ownership.

01

Encode

QR Code and Micro QR, automatic or explicit versions, error correction, masks, Kanji, ECI, FNC1 and Structured Append.

TypeScript types ↗
02

Decode

Recover payload bytes and metadata from sampled module grids, with Reed-Solomon correction and orientation normalization.

Zig API ↗
03

Render

Export SVG, PNG or raw RGBA pixels. Control module scale, quiet zone and colors. No external image toolkit required.

Examples ↗
Decoder scope. Zymbol accepts sampled QR module grids. It does not locate QR codes in photographs or perform camera capture.
