What it does

Encode, decode, and render QR Code and Micro QR symbols.

Encode

QR Code Model 2 and Micro QR. Choose a version and error correction level, or let Zymbol select them. Advanced encoding modes are also supported.

TypeScript API

Decode

Read data from a QR module grid, including error correction and orientation handling.

Zig API

Render

Export SVG, PNG or raw pixels. Set the colors, scale and quiet zone.

Examples

Decoding expects a module grid. Zymbol does not find QR codes in photos or read camera input.
