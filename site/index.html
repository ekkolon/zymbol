[ ABOUT THE LIBRARY ]

A small library for a precise format.

Create and read QR symbols from native Zig or JavaScript. Zymbol handles encoding, error correction and rendering. The browser playground below uses the published package, not a separate implementation.

02 / LIBRARY

The parts that matter.

Encoding, decoding and rendering. Nothing to install beyond the library.

01

Encode

QR Code Model 2 and Micro QR. Automatic or explicit versions, error correction, masks and advanced modes.

TypeScript API ↗
02

Decode

Read sampled module grids, recover data and correct errors with Reed-Solomon decoding.

Zig API ↗
03

Render

SVG, PNG and raw RGBA output. Set colors, scale and quiet zone without another image library.

Examples ↗

Decoder scope: sampled QR module grids. Zymbol does not locate symbols in photographs or capture camera input.
