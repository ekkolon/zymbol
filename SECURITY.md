# Security

## Supported versions

Security fixes are made against the current stable 1.x release. Older release
lines may receive fixes when the issue warrants it.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use **Report a vulnerability** in the repository's Security tab. Include:

- the affected QRz version or commit;
- a minimal reproducer when possible;
- the expected and observed behavior;
- the security impact.

Public disclosure should wait until a fix or mitigation is available.
